# Getting Started Demo

Hello-world example showing the simplest possible pub/sub flow with Orchestrix.

## What It Demonstrates
- Creating an `InMemoryMessageBus`
- Defining a simple `Event`
- Subscribing a handler function
- Publishing an event and seeing it processed

## Running

```bash
uv run python -m bases.orchestrix.getting_started_demo.demo_getting_started
```

This is the entry-level demo — start here to understand the basic message flow.
