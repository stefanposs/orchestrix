# web_gui_demo (Project)

This project demonstrates the full-stack Orchestrix web GUI, including the FastAPI backend (web_gui_demo base) and the React frontend (web_gui component).

## Features
- End-to-end demo: event sourcing, CQRS, projections, flow tracing, telemetry
- Docker Compose setup for backend and frontend
- Example configuration and test setup

## Usage
- Run with `docker-compose up`
- Access the web GUI at http://localhost:3000
- Backend API at http://localhost:8000
